# UI previews — 2026-10-10

These images show the redesigned console with explicit browser-test API fixtures. The account balances and record IDs are test data. They do not show live customer records or prove a financial posting.

Desktop captures use a 1440 × 960 viewport. The phone capture uses a 390 × 844 viewport. Full-page capture height can exceed the viewport height.
