# Redis outage or cache loss

1. Leave transfers enabled if PostgreSQL is healthy; Redis is never financial authority.
2. Requirement-bearing balance reads must use bounded primary fallback or return the truthful temporary-unavailable response.
3. Restart the worker or Redis service only through the approved platform procedure; do not manufacture stream events.
4. After Redis recovers, run `reconcile --rebuild-cache --tenant-id <tenant-uuid>` per impacted tenant.
5. Verify cache versions never regress and review `LedgerSyncRYEWViolation`; any violation is a critical incident.
